# Claude Certified Architect – Foundations: Study Prep

Personal study repository for preparing for the Claude Certified Architect – Foundations certification.

## Purpose

- Track study notes by exam domain
- Keep hands-on labs (Claude API, Claude Code, Agent SDK, MCP)
- Collect practice questions and review results

## Structure

| Folder | Contents |
| --- | --- |
| `notes/` | Notes organized by exam domain (fill in from the official exam guide) |
| `labs/` | Hands-on exercises and sample code |
| `practice-questions/` | Practice questions, answers, and explanations |
